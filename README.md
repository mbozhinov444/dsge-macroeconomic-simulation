# DSGE Macroeconomic Simulation

Python-based DSGE-style macroeconomic simulation project analyzing technology shocks, capital accumulation, consumption dynamics, and equilibrium adjustment mechanisms.

## Project Overview

This project implements a dynamic macroeconomic simulation framework inspired by DSGE and Real Business Cycle (RBC) modeling approaches. The model examines how technology shocks affect macroeconomic variables such as output, capital accumulation, investment, and consumption over time.

The project focuses on numerical simulation and dynamic equilibrium analysis using Python-based computational methods.

## Features

- Dynamic macroeconomic simulation
- Technology shock modeling
- Capital accumulation analysis
- Consumption and investment dynamics
- Equilibrium adjustment mechanisms
- Visualization of macroeconomic trajectories

## Tools & Libraries

- Python
- NumPy
- SciPy
- Matplotlib
- Jupyter Notebook
